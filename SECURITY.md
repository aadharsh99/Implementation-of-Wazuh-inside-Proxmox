# Security and Responsible Use

This repository documents an authorized security laboratory.

- Perform attack simulations only against systems you own or are explicitly authorized to test.
- Never commit credentials, API tokens, private keys, certificate keys, session cookies or unredacted public IP addresses.
- Review screenshots before publishing them.
- Treat detection alerts as investigation leads, not automatic proof of compromise.
- Test active response and blocking actions in a controlled environment before enabling them in production.
