# Source Notes

This repository is a portfolio-oriented restructuring of the supplied **Implementation of Wazuh inside Proxmox VE** report.

The repository preserves the report's implemented topology, versions, addresses, rule IDs, test scenarios, validation workflow and troubleshooting lessons. Where the report described a configuration concept rather than supplying a clean reusable configuration file, the repository uses a documented specification instead of inventing undocumented values.
